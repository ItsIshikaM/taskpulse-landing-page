# TaskPulse - SaaS Landing Page
LIVE DEMO LINK: https://taskpulse-landing-page.onrender.com
A fully responsive, modern SaaS landing page.

## Technologies Used
* HTML5
* Tailwind CSS (via CDN)
* Vanilla JavaScript (for mobile menu toggle & form validation)

## Setup & Local Instructions[cite: 6]
1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any modern web browser (Chrome, Firefox, Edge, Safari).
